DEAD ROOMS — вкладка «Мобы»
================================

В редакторе карт появилась вкладка «Мобы». Она редактирует data/mobs.json —
тот же файл, который читает игровой модуль mob.py. Никаких отдельных
форматов или конвертеров для созданных мобов не требуется.

Быстрый старт
-------------
1. Запусти launch_map_editor.bat.
2. Открой вкладку «Мобы».
3. Выбери существующего моба или нажми «Новый моб».
4. Настрой параметры и нажми «Сохранить моба».
5. Для проверки в запущенной игре нажми F5 (перезагрузка данных).

Вкладки редактора
-----------------
«Основное / хитбокс»
  ID — уникальный идентификатор (латиница, цифры, "_" и "-").
  HP, скорость, контактный урон, масса, опыт и масштаб урона.
  w/h — физический хитбокс, используемый физикой и столкновениями.
  draw — визуальный размер спрайта; он может отличаться от хитбокса.
  Основную текстуру можно выбрать с диска. Внешний файл копируется
  в assets/mobs/<mob_id>/, а путь записывается относительно assets.

«Поведение»
  JSON-настройка movement.py. Доступные типы:
    chase         — преследовать игрока;
    keep_distance — держать дистанцию;
    loop          — летать/двигаться по траектории;
    stand         — стоять на месте.
  В редакторе есть кнопки-шаблоны для трёх основных вариантов.
  Все параметры поведения (скорость, обзор, прыжок, дистанция, радиус,
  период, точки маршрута и т.п.) задаются в этом JSON.

«Атаки и комбо»
  Атаки задаются массивом JSON в порядке приоритета. Реализованные типы
  в attacks.py: melee, circle, shoot, leap.
  В каждой атаке можно задавать damage, windup, active, recovery,
  cooldown, range, min_range, range_y, knockback и специфичные параметры
  вроде reach, radius, projectile, burst, burst_gap.
  Для цепочки атак назначь первой атаке поле id, а поле next укажи равным
  id следующей атаки. Например, кнопка «Вставить пример серии из 2 атак»
  добавляет melee -> shoot. Параметр anims у атаки позволяет назначить
  собственные анимации фаз, если они предусмотрены игровой логикой.

«Текстуры и анимации»
  Основная текстура задаётся на первой вкладке.
  Для кадров анимаций создай папки внутри assets, например:
    assets/mobs/my_mob/idle/1.png
    assets/mobs/my_mob/idle/2.png
    assets/mobs/my_mob/move/1.png
    assets/mobs/my_mob/attack/1.png
  Выбери состояние и папку кадров, укажи FPS и зацикливание, нажми
  «Применить состояние к списку». Путь должен находиться внутри assets.
  Поддерживаемые состояния: idle, move, jump, windup, attack, recovery,
  hurt, death, roll. Кадры сортируются по имени файла.
  Формат анимаций совместим с anim.py.

«Доп. параметры»
  JSON для редких/специальных настроек, например flies, color, light,
  boss_visual и будущих параметров. Неизвестные поля существующих мобов
  сохраняются при редактировании.

Важно
-----
- ID должен быть уникальным.
- Атаки должны использовать типы, реализованные в attacks.py.
- Текстуры и папки анимаций должны лежать внутри assets.
- Удаление моба сразу сохраняется в data/mobs.json.
- Новый/изменённый моб сохраняется кнопкой «Сохранить моба».
- Перед экспериментами рекомендуется сделать копию data/mobs.json.

Постоянная панель предпросмотра (обновление редактора)
-----------------------------------------------------
Справа от вкладок всегда отображаются предпросмотр моба и сводка его
параметров. Сводка включает основные характеристики, физический хитбокс,
размер отрисовки, текстуру, поведение, все атаки/комбо, анимации и
дополнительные JSON-поля. Она обновляется по мере изменения настроек.

В панели предпросмотра:
  - моб смещён немного вправо, чтобы его было удобнее сравнивать с рамками;
  - синий контур показывает физический хитбокс;
  - пунктирная рамка показывает область отрисовки;
  - список «Ситуация» переключает idle/move/jump/attack и другие состояния;
  - кнопки «Кадр» позволяют листать кадры вручную;
  - «Проиграть/Пауза» запускает покадровый просмотр с FPS и loop из настроек.
  Если для состояния нет отдельной анимации, используется основная текстура.
  Поддерживаются кадры из папок анимаций и отдельные файлы кадров.
