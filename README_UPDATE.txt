DEAD ROOMS — апдейт v3: «Мелкие детали» (декор с пиксельной точностью в редакторе карт и в игре)
(ставится поверх v2; повторно применённое пропускается)

ЧТО ВНУТРИ
Раньше всё на карте стояло строго по клеткам 32x32. Теперь у карты есть слой мелких деталей "decor":
картинки (черепа, трещины, мох, паутина, камешки, надписи...) с произвольными координатами в пикселях,
своим размером, отражением и слоем. Это только картинки — на физику они не влияют.

В редакторе карт (launch_map_editor.bat -> вкладка «Карты») внизу новая панель «Мелкие детали»:
  - включи «Режим деталей»; выбери картинку (список или «Файл…»), размер подставится по картинке;
  - ЛКМ по пустому месту — поставить; ЛКМ по детали и тянуть — двигать; Ctrl+ЛКМ — поставить поверх другой;
    ПКМ — удалить;
  - шаг привязки 1 / 2 / 4 / 8 / 16 / 32 px; стрелки на клавиатуре двигают выбранную на 1 px (Shift — на 8),
    есть поля X, Y и кнопки ◄ ► ▲ ▼ (щёлкни по карте, чтобы она получила фокус);
  - справа ЛУПА ×4 вокруг выбранной детали (холст редактора вдвое меньше игры, поэтому 1 px там не видно);
  - слой «позади клеток» / «поверх клеток», отражение, размер, дублирование, порядок рисования, удаление.
Формат в файле карты (поле "decor"):
  {"sprite": "icons/stub_amulet.png", "x": 330, "y": 478, "w": 12, "h": 12, "flip": true, "z": "back"}
  x, y — левый верхний угол в пикселях карты (клетка = 32 px); sprite — путь внутри assets.

ЗАТРАГИВАЕТ
decor_panel.py (новый), map_editor.py, maps.py, container_panel.py, CLAUDE.md (документация, не критично).

УСТАНОВКА
1. Распакуйте архив в папку проекта (рядом с main.py), согласившись на замену apply_update.* и update_data.json.
2. Дважды щёлкните apply_update.bat (или: python apply_update.py).
3. Правки вносятся по содержимому файлов — ваши локальные изменения сохраняются. Перед правкой делается копия
   <файл>.bak_before_update. Повторный запуск безопасен. Если файл не подошёл, он НЕ изменяется, а скрипт
   пишет, что именно не нашлось, и предлагает заменить его целиком.
4. В игре нажмите F5 или перезапустите. Если играете из собранного exe — пересоберите его (build_exe.bat).

ОТКАТ
Верните файлы из копий *.bak_before_update (decor_panel.py можно просто удалить — редактор запустится как раньше).
