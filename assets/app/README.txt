Иконка игры (ярлык DEAD_ROOMS.exe, окно и панель задач)
=======================================================

icon.png  — основной файл. Квадратный PNG с прозрачностью, лучше 256x256 (минимум 64x64).
icon.ico  — необязательно. Если положить готовый .ico, при сборке EXE будет использован он (а PNG — для окна).

Что и когда меняется:
  * Окно игры и значок на панели задач берут icon.png при каждом запуске:
    заменили файл (в assets рядом с EXE) — перезапустили игру, пересобирать не нужно.
  * Иконка самого файла DEAD_ROOMS.exe (проводник, ярлык на рабочем столе) вшивается в EXE
    при сборке: заменили icon.png (или icon.ico) и запустите build_exe.bat заново.
    Если проводник показывает старую иконку — это кэш Windows (перезайдите в папку или перезапустите проводник).
