Мелкие детали с пиксельной точностью — обновление для DEAD_ROOMS

Что внутри (пути как в проекте):
  decor_panel.py      — НОВЫЙ файл: панель «Мелкие детали» в редакторе карт
  map_editor.py       — подключение панели (импорт, _ui, paint/erase, open/save, resize/clear)
  maps.py             — игра рисует слой "decor" (GameMap.draw_decor) + проверка в check()
  container_panel.py  — режим ящиков выключает режим деталей
  CLAUDE.md           — описание нового модуля
  decor.patch         — все правки одним diff-ом (для просмотра)

Установка: скопируй файлы в папку проекта с заменой (decor_panel.py — рядом с map_editor.py).
Старые файлы лучше сохранить (как *.bak_before_update).
Чтобы детали были видны в собранной игре, пересобери exe (build_exe.bat); при запуске из исходников — F5 в игре.

Как пользоваться: python map_editor.py -> вкладка «Карты» -> внизу панель «Мелкие детали» -> включи «Режим деталей».
  ЛКМ по пустому месту — поставить; ЛКМ по детали и тянуть — двигать; Ctrl+ЛКМ — поставить поверх другой;
  ПКМ — удалить; стрелки — сдвиг на 1 px (Shift — 8 px); Delete / Esc / Ctrl+D — удалить / снять выбор / дублировать.
  «Шаг привязки» — 1, 2, 4, 8, 16, 32 px. Справа — лупа ×4 вокруг выбранной детали.
Формат в файле карты (поле "decor"):
  {"sprite": "icons/stub_amulet.png", "x": 330, "y": 478, "w": 12, "h": 12, "flip": true, "z": "back"}
