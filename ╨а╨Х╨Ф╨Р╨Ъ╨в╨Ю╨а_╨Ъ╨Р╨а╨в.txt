ЗАПУСК РЕДАКТОРА КАРТ DEAD ROOMS

1. Откройте папку 2.9.
2. Дважды щёлкните launch_map_editor.bat.
3. Редактор запускается в отдельном окне.

Файл сам пробует запустить редактор через uv, затем через системный Python.
Для запуска нужен Python 3.10+; tkinter обычно входит в установщик Python для Windows.

Если Windows показывает предупреждение SmartScreen, запускайте только если доверяете файлам проекта.
Чтобы запускать игру, используйте существующий запуск игры как обычно.
