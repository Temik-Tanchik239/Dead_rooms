- **`key(g, k)`** — `Esc` → `g.menu_mode=None` + `pg.mouse.set_visible(not SETTINGS.get("mouse_aim", True))` (в режиме F3 сначала выходит из редактора); `1..5` и `KP1..KP5` → `g.menu_action(...)` (в редакторе цифры игнорируются).
- **`event(g, e)`** — ЛКМ по кнопке → `g.menu_action`; guard сети прямо в модуле (`_unavailable` → `g.fx.text` с мировыми координатами `cam+W//2, cam+VIEW_H//2−60`). - **`draw(g)`** — `g.scr.blit(g.menu_veil)`, кнопки из `g.menu_button`/`g.menu_button_selected` (fallback — цветные прямоугольники), слева от текста номер «1.
